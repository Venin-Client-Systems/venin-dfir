# Security Policy

VENIN DFIR parses untrusted forensic artefacts. Treat parser crashes, panics, uncontrolled memory growth, and evidence modification as security-relevant defects.

## Reporting

Open a GitHub security advisory or contact the maintainers privately once project ownership is established.

Do not attach sensitive evidence to public issues.

## Supported Versions

The project is pre-1.0. Security fixes target `main` until formal releases begin.
